Google Drive sync

Keeps your notes, highlights and links in step on all your devices, using one small file in your own Google Drive. The app can only see the file it makes. Nobody else can.

The two addresses Google asks for
Authorized JavaScript origin
Authorized redirect URI
How to get a Client ID (once, about 10 minutes)
  1. Go to console.cloud.google.com and sign in with your Google account. Create a new project called KJV Reader.
  2. Menu, APIs & Services, Library. Search for Google Drive API and click Enable.
  3. Menu, APIs & Services, OAuth consent screen (it may be called Google Auth Platform). Set App name KJV Reader, your email, and Audience External.
  4. Under Data access (Scopes), add .../auth/drive.file and save.
  5. Under Audience, click Publish app. (If you leave it in Testing, add your own email as a test user.)
  6. Credentials, Create credentials, OAuth client ID, type Web application. Paste the two addresses above into Authorized JavaScript origins and Authorized redirect URIs. Create.
  7. Copy the Client ID into the box above. (You do not need the secret.) Google can take a few minutes to start accepting a new setup.
